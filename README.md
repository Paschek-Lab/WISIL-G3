# Water in Solvate Ionic Liquids: Preserving Lithium Coordination While Enhancing Ionic Conductivity 

This repository contains a collection of input files described in the paper "Water in Solvate Ionic Liquids: Preserving Lithium Coordination While Enhancing Ionic Conductivity".

The repository is structured as follows:
- [simulations/](simulations/) contains the required input files for the molecular dynamics simulations of various systems. The simulations were performed with the GROMACS 2019.6 software package. All parameters different from default can be found in `SIMXX.mdp`, while `sim1out.mdp` includes all used parameters. For naming conventions, please refer to the Gromacs-2019.6-manual. The start configurations are stored in `START.gro`, and the corresponding force field parameters can be found in `topol.top`. An overview of the performed simulations is given in the [README](simulations/README.md) in the corresponding folder.
